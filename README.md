# DriveTalk — 3D 드라이빙 플레이그라운드

**레이싱과 초급 영어 듣기를 결합한 웹 게임입니다.** 약 640m의 파인 루프를 달리며 영어 지시를 주행 행동으로 수행합니다. 실제 Ferrari 458 Italia 3D 모델에 반사 도장·유리·실내·회전 휠을 적용했습니다. 좌우 입력은 추적 카메라 기준으로 수정했습니다. 참고 이미지와 같은 상용 게임의 모든 그래픽 효과를 재현하는 버전은 아닙니다.

## 영어 학습

1. 차고에서 **영어 듣기 미션**을 켜고 **영어 음성 확인**을 눌러 소리를 확인합니다.
2. 출발 전 표현 6개를 살펴볼 수 있습니다. 주행 중에는 영어 문장을 화면에 길게 표시하지 않습니다.
3. “Speed up”, “Keep left”, “Keep right”, “Slow down”, “Keep a steady speed”, “Come to a stop” 지시를 듣고 운전으로 답합니다. 도로 밖 주행은 성공으로 인정하지 않습니다.
4. 지시를 놓쳐도 게임은 멈추지 않습니다. HUD의 **EN ↻** 버튼으로 다시 들을 수 있습니다. 일시 정지 동안 음성과 미션 시간이 멈춥니다.
5. 주행을 마치면 **영어 피트 스톱**에서 뜻을 떠올리고 펼쳐 확인하며 다시 듣습니다. 스스로 기억한 표현과 미션 결과를 브라우저에 저장할 수 있습니다.

영어 음성은 기기·브라우저의 음성 합성을 사용합니다. 음성을 사용할 수 없으면 미션은 채점되지 않으며, 일반 주행과 종료 후 텍스트 복습은 계속 사용할 수 있습니다. 마이크, AI 대화, 발음 자동 평가, 서버 학습 기록은 포함하지 않습니다. 운전 미션 성공은 영어 실력의 진단 점수가 아닙니다.

## 바로 알아두실 점

- 브라우저에서 실행하는 3D 게임입니다. **실제 운전 중에는 사용하지 마세요.** 매 주행 시작 전에 안전 확인을 받습니다.
- API 키, 유료 AI 서비스, 회원가입은 필요하지 않습니다.
- GitHub는 소스 코드 보관 장소입니다. 저장소에 올리는 것만으로 게임 주소가 자동 생성되지는 않습니다.
- Chrome 또는 Edge 등 WebGL2가 지원되는 브라우저에서 그래픽 가속을 켜고 이용해 주세요.

## 컴퓨터에서 실행하기

첫 실행·빌드 시 공개 모델을 다운로드하므로 인터넷이 필요합니다. 이후 게임은 모델과 Draco 디코더를 자체 호스팅합니다. 모델 파일은 체크섬으로 검증됩니다.

Node.js **22**와 Git을 설치한 뒤, 터미널에서 다음 명령을 한 줄씩 실행합니다.

```bash
git clone https://github.com/philosophyAIEDU/260905racing.git
cd 260905racing
npm install -g pnpm@10.6.5
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 나타난 `http://localhost:4173` 주소를 브라우저로 여세요. `index.html` 파일을 더블클릭하는 방식으로는 실행되지 않습니다. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

차고의 458 ITALIA 색상 버튼으로 레이싱 레드·카본 블랙·펄 화이트를 선택할 수 있습니다. 선택은 브라우저에 저장됩니다.

1. 차고에서 **타임 어택** 또는 **자유 주행**을 선택합니다.
2. 안전 확인란에 체크하고 **주행 시작**을 누릅니다.
3. 3초 카운트다운이 끝나면 가속합니다. 첫 코너 전에는 속도를 줄여보세요.
4. 타임 어택은 체크포인트를 순서대로 통과해 3바퀴를 돌면 끝납니다. 자유 주행은 **주행 마치기**로 종료합니다.

## 조작

| 동작              | 키보드        | 게임패드  | 휴대폰                  |
| ----------------- | ------------- | --------- | ----------------------- |
| 가속              | W / ↑         | RT        | 가속 페달               |
| 제동·정지 후 후진 | S / ↓         | LT        | 제동 페달               |
| 좌우 조향         | A·D / ←·→     | 왼쪽 스틱 | 화면 스틱 / 기울기 옵션 |
| 드리프트          | Space / Shift | A         | 드리프트 버튼           |
| 코스 복귀         | R             | Y         | 화면 복귀 버튼          |
| 일시 정지·계속    | Esc           | Start     | 화면 정지 버튼          |
| 시점 전환         | C             | 설정 메뉴 | 설정 메뉴               |

복귀하면 마지막으로 통과한 체크포인트에 놓이며 기록에 3초가 더해집니다. 브라우저를 벗어나거나 다른 탭으로 이동하면 자동으로 일시 정지합니다. 기록과 설정은 현재 브라우저에만 저장합니다.

## 웹사이트로 배포하기

Netlify를 사용할 수 있습니다. 저장소 루트의 `netlify.toml`에 빌드 명령, 출력 폴더와 Node 버전을 설정했습니다. Netlify에서 이 저장소의 `main` 브랜치를 연결하세요. 실제 배포 완료 여부와 게임 URL은 Netlify에서 확인합니다. 다른 정적 호스팅에는 아래 값을 사용합니다.

| 설정               | 값                               |
| ------------------ | -------------------------------- |
| 프로젝트 기준 폴더 | 저장소 루트                      |
| Node 버전          | 22                               |
| 패키지 관리자      | pnpm 10.6.5                      |
| 설치 명령          | `pnpm install --frozen-lockfile` |
| 빌드 명령          | `pnpm build`                     |
| 공개할 폴더        | `apps/web/dist`                  |
| 환경변수 / API 키  | 없음                             |

직접 빌드한 결과를 올리려면 `pnpm build` 실행 후 `apps/web/dist` 폴더 안의 모든 파일을 함께 올립니다. 본 저장소 업로드는 호스팅 계정에서의 실제 배포를 포함하지 않습니다.

## 구성과 검증

React 19 + Vite 6 + TypeScript strict + Three.js r175 + React Three Fiber 9 + Rapier raycast vehicle controller를 사용합니다. pnpm workspace와 Turborepo로 구성했습니다.

| 위치                                                                              | 역할                                          |
| --------------------------------------------------------------------------------- | --------------------------------------------- |
| `apps/web`                                                                        | 3D 게임, 메뉴, HUD, 입력, 카메라              |
| `packages/game-core`                                                              | 조향·그립 계산, 코스, 랩·체크포인트 처리      |
| `packages/schema`                                                                 | 차량 JSON·브라우저 저장 데이터 검증           |
| `packages/ui`                                                                     | 공용 아이콘                                   |
| `config/vehicles/sprint.json`                                                     | 무게중심, 제동력, 서스펜션, 그립 등 차량 설정 |
| `apps/api`, `packages/learning-engine`, `packages/llm`, `packages/audio`, `tools` | 후속 단계용 경계만 예약; 현재 미구현          |

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:coverage
pnpm build
```

개발 중 `http://localhost:4173/?tune`를 열면 Leva 조정 패널이 나옵니다. 슬라이더 변경은 즉시 물리에 반영되며 영구 저장하려면 JSON을 수정해야 합니다. 배포 빌드에서는 조정 패널이 제거됩니다.

브라우저 통합 테스트는 다음 명령으로 실행합니다.

```bash
pnpm exec playwright install chromium
pnpm test:e2e
```

GitHub Actions에도 타입 검사, 린트, 단위 테스트, 빌드, 브라우저 통합 테스트를 등록했습니다. 최신 성공 여부는 저장소 **Actions** 탭에서 확인합니다.

**검증 범위와 남은 제한은 [단계별 검증 보고서](docs/phase-0-1-review.md)를 참고해 주세요.** 60fps나 실제 휴대폰·게임패드 검증을 완료했다고 주장하지 않습니다.
