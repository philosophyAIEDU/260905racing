## 1. 🎯 작업 목표

레이싱 게임 수준의 3D 그래픽·차량 물리·사운드를 가진 드라이빙 게임 안에, 실시간 음성 대화 기반 영어 학습을 **게임 메커니즘 자체로** 통합한 크로스플랫폼 앱을 구축한다.

**한 문장 정의:** "운전이 재미있어서 계속 하다 보니 영어가 늘어 있는 앱." 학습 화면 위에 자동차를 얹은 앱이 **아니다.**

**성공 기준 (제품 KPI)**

- D7 리텐션 30% 이상 (학습앱 평균 대비 2배)
- 세션당 평균 발화(영어) 횟수 15회 이상
- 세션당 평균 플레이 12분 이상
- 신규 단어 7일 후 재인출 정답률 75% 이상

## 2. 📋 배경 컨텍스트 및 제품 원칙

### 2.1 반드시 지켜야 할 설계 원칙 5가지

| # 원칙 구현상 의미  |                 |                                                                                |
| ------------ | --------------- | ------------------------------------------------------------------------------ |
| P1           | **Game-first**  | 학습 요소를 전부 제거해도 "그냥 재미있는 드라이빙 게임"이어야 한다. 학습이 게임을 방해하면 학습을 깎는다.                  |
| P2           | **인지부하 분리**     | 주행 중에는 **오디오 전용**(듣기·말하기). 정차/피트인 상태에서만 **텍스트·문법·복습** 노출. 주행 중 긴 텍스트 읽기 UI 금지. |
| P3           | **발화가 곧 조작**    | 영어 발화가 게임 상태를 실제로 바꿔야 한다. (내비 지시를 영어로 말해야 경로가 열림, 주유소에서 주문해야 연료 충전 등)          |
| P4           | **실패는 계속 굴러간다** | 오답/발음 실패 시 게임 정지 금지. 페널티는 시간·연료·점수로만. 모달 팝업으로 흐름을 끊지 않는다.                      |
| P5           | **개인화는 데이터로**   | 난이도·어휘·NPC 발화 속도는 하드코딩이 아니라 학습자 모델(CEFR + FSRS 상태)에서 파생된다.                     |

### 2.2 핵심 게임 루프

```
[차고/피트] → 미션 선택 → [주행 시작]
   ↓
주행 중 이벤트가 스트리밍으로 발생:
  · 도로 표지판 = 어휘 인풋 (Merge, Yield, Detour Ahead...)
  · 무전(라디오) NPC = 실시간 음성 대화 (길 안내, 배달 지시, 잡담)
  · 스피드 게이트 = 리스닝 문제 (들은 대로 올바른 게이트 통과)
  · 픽업 아이템 = 목표 어휘 수집
   ↓
[결승/도착] → 리절트 화면 → 정차 상태에서만 텍스트 복습(FSRS 큐)
   ↓
보상(차량 파츠·페인트·신규 코스) → 차고로 복귀

```

### 2.3 안전 고지 (법적 필수)

앱 최초 실행 및 매 세션 시작 시 **"실제 운전 중 사용 금지"** 경고를 표시하고 동의를 받는다. 기기 이동 속도가 감지되면(Geolocation, 선택적) 세션을 자동 차단하는 옵션 제공. 이 요구사항은 삭제·축소 대상이 아니다.

### 3.2 대안 스택 (필요 시에만)

모바일 네이티브에서 **콘솔급** 그래픽이 반드시 필요하면 \*\*Unity 6 (URP) + C#\*\*으로 전환한다. 단 그 경우 개발 속도와 LLM 연동 편의성이 크게 떨어진다. **기본 결정: Web/PWA 스택으로 시작하고, 그래픽 벤치마크 미달 시에만 Unity로 전환.** `[[결정필요]]` — 이 결정을 뒤집을 거면 Phase 0 이전에 확정할 것.

### 3.3 AI 모델 계층

```
대화 브레인 : gpt-6-astra   (2026-09-03 출시, 1M 컨텍스트)
경량/저비용 : 상위 모델의 mini/경량 티어 (실시간 판정·짧은 응답용)
음성        : Realtime API (speech-to-speech, 서버 릴레이 경유)
발음 평가   : 전용 발음 평가 API 또는 음소 정렬(forced alignment) 기반 스코어러

```

> **필수 구현 규칙:** 모델 ID를 코드에 하드코딩하지 말 것. `packages/llm`의 provider adapter를 통해서만 접근하고, 모델 ID는 환경변수(`MODEL_DIALOGUE`, `MODEL_FAST`, `MODEL_REALTIME`)로 주입한다. GPT-6 Astra는 출시 직후 단계적 롤아웃 중이며 티어별 접근 권한과 가격($10/$50 per 1M tokens 수준)이 유동적이므로, **모델 교체가 1줄 환경변수 변경으로 끝나야 한다.** 접근 불가 시 자동 폴백 체인을 구성할 것.

## 4. 🏗 아키텍처 요구사항

### 4.1 모노레포 구조

```
drivetalk/
├─ apps/
│  ├─ web/                  # React 19 + R3F 게임 클라이언트
│  └─ api/                  # Hono 서버 (LLM 프록시, 학습 상태, 인증)
├─ packages/
│  ├─ game-core/            # 순수 TS: 물리 튜닝, 게임 루프, 이벤트 스케줄러 (React 의존 0)
│  ├─ learning-engine/      # FSRS 스케줄러, CEFR 레벨링, 어휘 모델 (순수 TS)
│  ├─ llm/                  # provider adapter, 스키마, 프롬프트 템플릿, 폴백
│  ├─ audio/                # 엔진 사운드 신스, 3D 오디오, 더킹(ducking)
│  ├─ ui/                   # 공용 HUD 컴포넌트
│  └─ schema/               # zod 스키마 + Drizzle 스키마 (단일 진실 공급원)
└─ tools/                   # 에셋 파이프라인 (glTF 압축, KTX2 변환)

```

### 4.2 렌더 루프 규칙 (성능의 핵심)

- **게임 상태는 React state가 아니다.** 차량 위치·속도·RPM은 Zustand의 non-reactive ref 또는 mutable store에 두고 `useFrame`에서 직접 갱신한다.
- **프레임당 React 리렌더 0회**가 목표. HUD 숫자(속도계 등)는 `useRef` + 직접 DOM 텍스트 갱신 또는 throttled subscribe(최대 10Hz)로 처리한다.
- `useFrame` 안에서 객체·배열·클로저 신규 할당 금지. 벡터·쿼터니언은 모듈 스코프에 재사용 인스턴스를 둔다.
- 물리 tick은 고정 60Hz, 렌더는 가변. 보간(interpolation) 적용.

### 4.3 LLM 통합 규칙

- API 키는 **절대** 클라이언트에 노출하지 않는다. 모든 호출은 `apps/api` 경유.
- 게임 상태를 바꾸는 모든 LLM 출력은 **structured output(JSON schema)** 으로 받는다. 자유 텍스트 파싱 금지.
- 사용자당 일일 토큰 상한과 세션당 상한을 서버에서 강제한다. 초과 시 사전 생성된 정적 대화 팩으로 우아하게 폴백.
- 자주 쓰이는 NPC 대사·표지판 문구는 빌드 타임에 **사전 생성 후 캐시**한다. 런타임 LLM 호출은 "진짜 개인화가 필요한 곳"에만.
- 모든 LLM 호출에 타임아웃(대화 3s, 판정 800ms)과 재시도 1회, 그리고 폴백 응답을 반드시 구현한다.

## 5. 📝 상세 요구사항

### 5.1 차량 물리 및 조작 (필수)

- Rapier의 raycast vehicle controller 기반. 서스펜션 4륜 독립, 스티프니스/댐핑/트래블 파라미터화.
- 타이어 그립: 종방향/횡방향 슬립 곡선 구현. 슬립 앵글 초과 시 드리프트 발생.
- 조작 입력: 키보드(WASD/화살표), 게임패드(Gamepad API, 아날로그 트리거), 모바일 터치(가상 스틱 + 기울기 옵션).
- 아케이드 지향 튜닝: 시뮬레이터 아님. **첫 30초 안에 누구나 코너를 돌 수 있어야 한다.** 어시스트(트랙션·스티어링) 기본 ON, 설정에서 OFF 가능.
- 차량 파라미터는 코드가 아닌 `config/vehicles/*.json`으로 분리하고 개발 모드에서 leva 패널로 실시간 튜닝 가능하게 한다.

### 5.2 렌더링 및 비주얼 (필수)

- **HDRI 기반 IBL** + 방향광 1개 + CSM(Cascaded Shadow Maps).
- 차량 셰이더: clearcoat 적용 PBR, 환경 반사, 색상 커스터마이징 가능.
- 후처리 체인: ToneMapping(ACES) → Bloom → Motion Blur(속도 연동) → SMAA. 저사양 프리셋에서는 Bloom+SMAA만.
- 성능 기법 필수 적용: **인스턴싱**(도로변 오브젝트·나무·가드레일), **LOD 3단계**, **프러스텀 컬링**, **텍스처 아틀라스**, 원거리는 **임포스터/빌보드**.
- 에셋 규격: glTF 2.0 + Draco(지오메트리) + KTX2/Basis(텍스처) + Meshopt. 원본 fbx/png 커밋 금지.
- 품질 프리셋 4단계(Low/Medium/High/Ultra) + 최초 실행 시 자동 벤치마크로 프리셋 결정. 프레임레이트가 45fps 미만으로 3초 지속되면 자동 하향.
- 스카이박스는 시간대 3종(주간/석양/야간) 이상, 날씨는 최소 맑음/비 2종(비: 노면 반사 강화 + 파티클 + 와이퍼 사운드).

### 5.3 오디오 (필수)

- 엔진음: RPM에 따라 pitch/gain 크로스페이드하는 다중 루프 샘플 방식. 단일 루프 반복 금지.
- 3D 포지셔널 오디오(PannerNode)로 상대 차량·환경음 배치.
- **오디오 더킹 필수:** NPC 음성 재생 또는 사용자 발화 감지 시 엔진음·BGM을 -12dB 감쇠. 영어 음성이 항상 최우선 채널이다.
- 사용자 마이크 입력에는 에코 캔슬레이션·노이즈 서프레션 활성화(`getUserMedia` constraints).

### 5.4 영어 학습 엔진 (필수)

- **어휘 DB:** CEFR A2\~B2 태깅, 최소 1,500개. 각 항목은 `{ lemma, pos, cefr, ipa, ko_gloss, example_en, example_ko, audio_url, contexts[] }`. `contexts`는 게임 내 등장 가능 지점(표지판/무전/주유소 등).
- **스케줄러:** SM-2 대신 **FSRS(최신 버전)** 알고리즘 구현. 각 항목은 stability, difficulty, retrievability 상태를 가진다. `packages/learning-engine`에 순수 함수로 구현하고 단위 테스트 필수.
- **인출 방식 3종:** ① 리스닝 게이트(들은 단어의 게이트 통과) ② 발화 인출(NPC 질문에 영어로 답변) ③ 정차 시 텍스트 복습.
- **적응형 난이도:** 최근 20회 인출 정답률이 85% 초과면 난이도 상승(NPC 발화 속도 +10%, 어휘 밴드 상향), 60% 미만이면 하향. 급격한 변화 금지 — 단계당 최대 1스텝.
- **오답 관리:** 틀린 항목은 같은 세션 내 최소 1회 다른 형태로 재등장.

### 5.5 실시간 음성 NPC (필수)

- Realtime speech-to-speech 파이프라인. 사용자는 푸시투토크(스페이스바/트리거) 또는 VAD 자동 감지 중 선택.
- **레이턴시 예산:** 사용자 발화 종료 → NPC 첫 오디오 바이트까지 **700ms 이하**. 초과 시 "무전 잡음" 필러 사운드로 체감 지연 은폐.
- **바지인(barge-in) 지원:** 사용자가 말을 시작하면 150ms 내 NPC 음성 중단.
- NPC 페르소나 최소 3종: 관제탑(지시형), 정비사(캐주얼), 승객(잡담형). 각각 다른 액센트·속도. 페르소나는 시스템 프롬프트 템플릿으로 `packages/llm`에 분리.
- **NPC 대사 제약:** 학습자 CEFR 레벨 +1 이내 어휘만 사용, 1턴 최대 2문장, 반드시 학습자에게 발화를 유도하는 질문이나 지시로 끝난다. 이 제약을 시스템 프롬프트에 명시하고, 응답 검증 레이어에서 문장 수를 검사한다.
- 대화 상태는 게임 상태와 동기화된다. 예: 연료 20% 미만이면 정비사가 먼저 무전을 건다.

### 5.6 발음 평가 (필수)

- 단어·문장 단위 점수(0\~100)와 **음소 단위 피드백** 제공.
- 한국어 화자 특화 오류 우선 탐지: `/r/–/l/`, `/f/–/p/`, `/v/–/b/`, `/θ/–/s/`, 어말 자음군, 강세 위치.
- 피드백은 주행 중에는 짧은 사운드+색상 신호로만, 상세 음소 리포트는 정차 후 리절트 화면에서.
- 낮은 점수에 대해 **부정적 표현 금지.** "다시 한번" 계열의 중립·격려 톤으로 통일.

### 5.7 진행·보상 시스템 (필수)

- 학습 성과가 게임 보상으로 직결: 어휘 마스터리 → 차량 파츠 해금, 연속 학습일 → 신규 코스, 발음 점수 → 페인트/데칼.
- 스트릭(연속일)은 표시하되 **끊겼을 때 죄책감 유발 UI 금지.** 복구 아이템 제공.
- 리절트 화면: 주행 성적(랩타임/순위) + 학습 성적(신규 어휘/인출 정답률/발음)을 **동등한 비중**으로 표시.

### 5.8 접근성 및 현지화 (필수)

- 자막 항상 제공(NPC 음성 전체). 크기 3단계.
- 색맹 대응: 게이트·신호를 색상 단독으로 구분하지 않는다(형태·아이콘 병행).
- 모션 감소 옵션(카메라 셰이크·모션블러 비활성화), 광과민성 대응(플래시 제한).
- UI 언어 ko/en 전환. 학습 대상 콘텐츠는 항상 영어.
- 키보드 전용 조작으로 전체 플레이 가능해야 한다.

## 7. 📐 코드 스타일 가이드

- TypeScript strict 전면 적용. 공개 함수는 명시적 반환 타입.
- 네이밍: 컴포넌트 `PascalCase`, 훅 `useCamelCase`, 상수 `SCREAMING_SNAKE`, 파일 `kebab-case.ts` (컴포넌트 파일만 `PascalCase.tsx`).
- 함수 40줄 초과 시 분리. 파일 300줄 초과 시 분리.
- 주석은 "왜"만 적는다. "무엇"은 코드가 말하게 한다. 단 **물리·수학 계산과 셰이더에는 수식·단위·좌표계를 반드시 주석으로 명시**한다.
- 런타임 경계(API 응답, LLM 출력, localStorage)는 전부 zod로 검증.
- 에러: 삼킴 금지. `Result<T, E>` 패턴 또는 명시적 throw + 상위 바운더리 처리.
- ESLint(flat config) + Prettier + `tsc --noEmit`를 pre-commit(husky + lint-staged)에서 강제.

## 9. 🚀 Phase별 구현 계획 (한 번에 하나씩 실행)

### Phase 0 — 기반 (0.5일)

모노레포 스캐폴딩, TS/ESLint/Prettier/Vitest 설정, CI 파이프라인, 빈 R3F 캔버스에 그리드+조명 렌더.

### Phase 1 — 주행이 재미있어야 한다 (핵심)

Rapier 차량 컨트롤러, 서스펜션/그립 튜닝, 3인칭 카메라(속도 연동 FOV·러버밴딩), 키보드+게임패드+터치 입력, 플레이스홀더 트랙 1개, leva 튜닝 패널.
**DoD:** 학습 요소 0개 상태로 5분간 운전해도 재미있다. 코너에서 드리프트가 나고, 카메라가 멀미를 유발하지 않는다. 60fps 유지.

### Phase 2 — 비주얼 승격

PBR 차량 셰이더, HDRI+IBL, CSM 그림자, 후처리 체인, 인스턴싱된 환경 오브젝트, LOD, 품질 프리셋 + 자동 벤치마크, 시간대 3종.
**DoD:** 스크린샷이 "학습 앱"이 아니라 "레이싱 게임"으로 보인다. 성능 예산(6.1) 전 항목 충족. 저사양 프리셋에서 모바일 30fps.

### Phase 3 — 오디오 + 학습 엔진 (병렬 가능)

RPM 기반 엔진음, 3D 오디오, 더킹. `learning-engine` FSRS 구현 + 어휘 DB 스키마 + 시드 300개.
**DoD:** 엔진음이 속도 변화에 자연스럽게 반응. FSRS 단위 테스트 90% 커버리지 통과.

### Phase 4 — LLM 및 음성 통합

`packages/llm` provider adapter, 서버 프록시, structured output 스키마, Realtime 음성 파이프라인, NPC 페르소나 3종, 바지인, 폴백 체인, 토큰 상한.
**DoD:** 무전 NPC와 영어로 30초 이상 왕복 대화 가능. 레이턴시 700ms 이하. 네트워크를 끊어도 크래시 없이 정적 대화 팩으로 전환.

### Phase 5 — 학습 메커니즘의 게임화

리스닝 게이트, 표지판 어휘 인풋, 픽업 아이템, 발화가 경로를 여는 내비 미션, 발음 평가 연동, 적응형 난이도.
**DoD:** 원칙 P3 충족 — 영어를 말하지 않고는 특정 미션을 클리어할 수 없다. 오답이 게임 흐름을 끊지 않는다(P4).

### Phase 6 — 진행·보상·마감

리절트 화면, 파츠/페인트 해금, 스트릭, 온보딩, 안전 고지, 접근성 옵션 전체, PWA 오프라인, E2E·성능 회귀 CI.
**DoD:** 8장 테스트 전부 통과. 신규 사용자가 도움 없이 온보딩→첫 주행→복습까지 완료.
